# Descrição do desafio escolhido
A IA foi aplicada para desenvolver uma interface responsiva em HTML, CSS e JavaScript puro, integrada a um dashboard com estatísticas visuais das tarefas. A aplicação permite criar, editar, deletar e concluir tarefas, além de estipular horários ao longo do dia. Também é possível marcar os dias concluídos e acompanhar o percentual de progresso até a data final de conclusão, com status e prioridade das tarefas, mantendo um gráfico intuitivo e simples de produtividade.
